# CS173: Tiny GRPO-based fine-tuning
This is a simple implementation of GRPO generated by `gpt-oss:120b` in GenAI RCAC Studio to fine-tune an LLM to successfully count the number of vowels in a string for CS173.

## The task
Given an arbitrary string, count the number of vowels in it.

## The reward structure
- +1.0 reward is given if the model outputs the correct number of vowels.
- 0.0 reward is given if the model does not output the correct number of vowels.
